# Motion Defined: Ballet Edition

A 3D ballet term dictionary built in Godot 4 (GDScript), designed to help dance students and teachers search for ballet steps and see both a written description and a visual demonstration by a 3D character.

## Features

- Searchable dictionary of ballet terminology
- 3D character demonstrations of steps
- Character selection (currently male and female supported)
- Rotate, zoom, pause/play and scrub animations
- Cross-platform support (Windows/Mac), including platform-specific keyboard shortcuts
- Built entirely in Godot 4 / GDScript

## Why I built this

As an RAD-certified ballet teacher, I wanted to build a resource that could help students and teachers quickly find a term and see both a definition and demonstration of the movement. In addition, I wanted users to be able to fully engage with the model to be able to study the movements from different angles and at different speeds.

## Status

Fully functional prototype with three searchable terms, actively in development.

## Tech

- **Engine:** Godot 4
- **Language:** GDScript
